# Учёт оплат учебного центра

Тестовое задание Ecomdev: API учеников и оплат, отчёт «должники за месяц», мобильная веб-страница и Telegram-бот.

**Стек:** Node.js + TypeScript, Fastify, Prisma, SQLite, zod · React + Vite · grammY · Vitest · Docker.

## Запуск с нуля

Нужен Node.js 20+ (проверено на 24) и git.

```bash
git clone https://github.com/Abdulloh1623/ecomdev-payments.git
cd ecomdev-payments
cp server/.env.example server/.env      # Windows: copy server\.env.example server\.env
npm run setup                           # зависимости + миграции + демо-данные
npm run dev                             # API :3000 и веб :5173 с hot reload
```

- Веб-страница: http://localhost:5173
- API: http://localhost:3000, Swagger UI: http://localhost:3000/docs

Одним процессом, как в продакшене (сервер сам раздаёт собранный фронтенд):

```bash
npm run build
npm start                               # веб + API на http://localhost:3000
```

### Docker

```bash
docker compose up --build               # http://localhost:3000
```

База хранится в volume `data`, при первом старте добавляются демо-данные (`SEED_DEMO=0` — без них).
Другой порт: `HOST_PORT=8080 docker compose up --build`. Токен бота и `ADMIN_IDS` подхватываются из `server/.env`.

### Тесты

```bash
npm test                                # 45 тестов, отдельная БД server/prisma/test.db
npm run typecheck
```

## API

Все ошибки в одном формате: `{ "error": { "code", "message", "details?" } }`. Полная схема — в Swagger (`/docs`).

| Метод | Путь | Описание |
|---|---|---|
| GET | `/students?group=` | Список учеников (фильтр по группе необязателен) |
| POST | `/students` | Создать: `{ name, phone, group, monthlyFee }` → 201 |
| GET | `/students/:id` | Ученик по id |
| PATCH | `/students/:id` | Изменить любые поля |
| DELETE | `/students/:id` | Удалить (мягко) → 204 |
| POST | `/payments` | Оплата: `{ studentId, amount, date? }` → 201, `date` по умолчанию — сегодня |
| GET | `/students/:id/payments` | Оплаты ученика, новые сверху (то же: `GET /payments?studentId=`) |
| GET | `/debtors?month=YYYY-MM` | Должники за месяц; без `month` — текущий |

```bash
curl -X POST localhost:3000/students -H 'content-type: application/json' \
  -d '{"name":"Азиз Каримов","phone":"+998901234567","group":"A1","monthlyFee":500000}'
curl -X POST localhost:3000/payments -H 'content-type: application/json' \
  -d '{"studentId":1,"amount":200000,"date":"2026-10-05"}'
curl 'localhost:3000/debtors?month=2026-10'
```

Ответ `/debtors`:

```json
{
  "month": "2026-10", "count": 1, "totalDebt": 300000,
  "debtors": [{ "id": 1, "name": "Азиз Каримов", "phone": "+998901234567", "group": "A1",
                "monthlyFee": 500000, "paid": 200000, "debt": 300000, "deleted": false }]
}
```

### Как считаются должники

- Оплата относится к месяцу **по своей дате** (`date` хранится как `YYYY-MM-DD`, без часового пояса).
- `debt = monthlyFee − сумма оплат за месяц`; в отчёт попадают только `debt > 0`, в том числе те, кто не платил вовсе.
- Переплата на другие месяцы не переносится.
- Ученик учитывается с месяца, в котором его добавили; удалённый — до месяца удаления включительно
  (флаг `deleted: true`). Границы месяцев считаются в часовом поясе `APP_TIMEZONE` (по умолчанию `Asia/Tashkent`).
- Сортировка — по убыванию долга.

### Прочие решения

- **Мягкое удаление:** удалённый ученик пропадает из списков, но его оплаты и история долгов сохраняются.
  Вносить оплату удалённому нельзя (404).
- **Деньги** — целые числа (без копеек/тийинов), от 1 до 1 000 000 000.
- **Валидация:** телефон — 7–20 символов из цифр, пробелов, `+ - ( )`; дата проверяется на существование (`2026-02-30` → 400).

## Веб-страница

Вкладки внизу экрана, рассчитаны на телефон:

- **Должники** — переключение месяцев, итоги, прогресс оплаты, звонок по нажатию на телефон.
  «Внести оплату» открывает форму с выбранным учеником и остатком долга.
- **Оплата** — поиск ученика, сумма, дата, история оплат выбранного ученика.
- **Ученики** — добавление и удаление.

## Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и впишите токен в `server/.env` → `TELEGRAM_BOT_TOKEN`.
2. Запустите сервер и напишите боту `/start` — он ответит вашим Telegram ID.
3. Впишите ID в `ADMIN_IDS` (несколько — через запятую) и перезапустите сервер.

Команды: `/debt` — должники текущего месяца; `/pay <id ученика> <сумма>` — оплата сегодняшним числом
(сумму можно писать с пробелами: `/pay 3 500 000`). Бот отвечает, сколько ещё осталось заплатить за месяц.

Бот работает в том же процессе, что и API (long polling). Без токена он просто не запускается, API работает.
Доступ — только для `ADMIN_IDS`, потому что бот показывает телефоны и меняет данные.

## Структура

```
server/
  prisma/          схема, миграции, демо-данные
  src/
    routes/        HTTP-слой (Fastify + zod-схемы)
    services/      бизнес-логика: ученики, оплаты, должники (её же использует бот)
    lib/dates.ts   месяцы, даты, часовые пояса
    bot.ts         Telegram-бот
    app.ts         сборка приложения, формат ошибок, Swagger, раздача фронтенда
  test/            Vitest: API через app.inject, отчёт должников, юнит-тесты
web/src/           React: вкладки должников, оплаты, учеников
```

4. **Масштаб.** PostgreSQL, пагинация и поиск в списках, бот на webhook вместо long polling.
